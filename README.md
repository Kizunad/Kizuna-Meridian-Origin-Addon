# Kizuna 经脉出身

Minecraft 26.2 Fabric 附属：玩家第一次进世界时抽几个出身、从里面选定一个，定了以后游戏里没有办法改。
每个出身带一份天赋和一份天生的麻烦。本仓只管「有哪些出身、谁选了哪个」：出身写在数据包里，
天赋和麻烦怎么兑现由管那块机制的附属各自登记实现，本仓不带任何具体天赋。

行为、数据格式、登记接口、指令、配置和验证记录统一维护在 [Wiki](docs/wiki/Home.md)。
